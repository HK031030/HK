# 🚗 驾校预约管理系统（前端）

> 一个基于 Vue 3 的前后端分离驾校预约管理系统前端项目
> 支持 **管理员 / 教练 / 学员** 多角色协同，包含课程预约、权限控制、实时通知与智能助教功能。

---

## 📌 项目简介

本项目为 **驾校预约管理系统的前端部分**，采用前后端分离架构，
主要解决传统驾校中 **课程安排混乱、预约效率低、信息沟通不及时** 等问题。

系统围绕「**课程管理 + 预约流程 + 角色权限控制**」展开，
为管理员、教练和学员提供差异化操作界面与功能支持，提升整体管理效率与用户体验。

>
> * 本仓库仅包含 **前端源码**
> * 后端由团队成员负责（Spring Boot + MyBatis）

## 👥 用户角色与功能

### 👑 管理员（Admin）

* 用户管理：新增 / 编辑 / 删除用户，角色分配
* 课程管理：发布课程、调整时间、统计预约数据
* 预约管理：查看全局预约、取消异常预约
* 公告管理：发布、编辑、置顶系统公告
* 数据监控：查看系统运行与用户活跃情况

### 🧑‍🏫 教练（Coach）

* 课程管理：管理本人负责的课程
* 预约查看：查看学员预约情况
* 资源管理：上传教学视频、资料
* 公告查看：获取系统及教学相关通知

### 🎓 学员（User）

* 课程预约：浏览课程、选择时段进行预约
* 预约管理：取消预约、查看历史记录
* 学习中心：查看教练上传的学习资料
* 个人信息：头像上传、资料修改、密码管理

## 🏗️ 前端架构设计

项目采用模块化、组件化的多层架构设计：

```
src/
├─ api/          # 接口请求封装
├─ assets/       # 静态资源
├─ components/   # 公共组件（AI 助手、图表等）
├─ hooks/        # 自定义 Hooks（WebSocket 等）
├─ router/       # 路由配置与权限控制
├─ store/        # Pinia 状态管理
├─ utils/        # 工具函数封装
├─ views/        # 页面组件
└─ styles/       # 全局样式
```

通过 **RBAC 权限模型** 实现菜单、路由、操作级权限的统一控制。

---

## 🔐 权限控制设计（RBAC）

* 基于 **角色（Role）- 权限（Permission）模型**
* 登录后从 Token / 用户信息中解析角色
* 通过 `hasPermission()` 控制：

  * 菜单是否显示
  * 按钮是否可用
  * 路由是否可访问
* 结合 Vue Router 全局守卫，实现路由级拦截

👉 有效实现 **Admin / Coach / User 三端功能隔离**

## ⚡ 核心功能亮点

### ✅ 智能预约流程

* 动态加载课程与可预约时段
* 自动判断是否已预约、剩余名额
* 支持预约 / 取消预约全流程
* 前端状态与后端数据保持同步

### 🤖 AI 智能助教

* 集成 **讯飞星火大模型 API**
* 通过 **SSE 流式响应**解析实现打字机效果
* 实时问答，降低用户等待焦虑

### 📡 实时通知（WebSocket）

* 封装 WebSocket 客户端类
* 实现心跳检测、断线重连、消息分发
* 用于预约成功 / 取消等实时通知推送

### 📊 管理员数据大屏

* 使用 ECharts 构建可视化监控界面
* 留言板数据与监控大屏实时联动
* 支持系统状态与用户反馈直观展示

### 🖼️ Base64 头像上传

* 前端图片压缩 + Base64 编码上传
* 即时预览、无需文件服务器
* 头像信息持久化存储（localStorage）
